# 🔢 NumPy & Pandas - Data Manipulation

Modul ini mengajarkan NumPy dan Pandas, dua library fundamental untuk data science dan machine learning.

## 📚 Materi

1. **01_numpy_basics.ipynb**
   - NumPy Arrays
   - Array Operations
   - Broadcasting
   - Linear Algebra Basics
   - Random Numbers
   
2. **02_pandas_dataframes.ipynb**
   - Series & DataFrames
   - Reading/Writing Data (CSV, Excel)
   - Data Selection & Filtering
   - Handling Missing Data
   - Basic Statistics
   
3. **03_data_manipulation.ipynb**
   - GroupBy Operations
   - Merging & Joining
   - Pivot Tables
   - String Operations
   - Date/Time Handling

## ⏱️ Estimasi Waktu

- Total: 1-2 minggu
- Per notebook: 3-5 jam
- Practice: 5-7 jam

## 🎯 Learning Objectives

Setelah menyelesaikan modul ini, Anda akan bisa:
- ✅ Membuat dan manipulasi NumPy arrays
- ✅ Melakukan operasi matematika pada arrays
- ✅ Membaca dan menganalisis data dengan Pandas
- ✅ Membersihkan dan transform data
- ✅ Melakukan exploratory data analysis (EDA)

## 🚀 Cara Mulai

1. Pastikan sudah install NumPy & Pandas:
```bash
pip install numpy pandas
```

2. Buka Jupyter Notebook:
```bash
jupyter notebook
```

3. Mulai dari `01_numpy_basics.ipynb`

## 📝 Prerequisites

✅ Sudah menyelesaikan 01-python-basics
- Variables & Data Types
- Lists & Dictionaries
- Functions
- List Comprehensions

## 💡 Tips

- NumPy arrays lebih cepat dari Python lists untuk data besar
- Pandas built on top of NumPy
- Gunakan vectorization, hindari loops manual
- Index dimulai dari 0 (seperti Python lists)
