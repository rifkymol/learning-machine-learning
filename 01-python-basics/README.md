# 🐍 Python Basics untuk Machine Learning

Folder ini berisi tutorial dasar-dasar Python yang diperlukan untuk machine learning.

## 📚 Materi

1. **01_python_fundamentals.ipynb**
   - Variables & Data Types
   - Lists, Tuples, Dictionaries
   - Loops & Conditionals
   - Functions

2. **02_numpy_introduction.ipynb**
   - Arrays & Matrices
   - Array Operations
   - Broadcasting
   - Statistical Functions

3. **03_pandas_basics.ipynb**
   - DataFrames & Series
   - Reading data (CSV, Excel)
   - Data selection & filtering
   - Data cleaning

## ⏱️ Estimasi Waktu

- Total: 1-2 minggu
- Per notebook: 2-4 jam

## 🎯 Learning Objectives

Setelah menyelesaikan modul ini, Anda akan bisa:
- ✅ Menulis kode Python dasar
- ✅ Manipulasi data dengan NumPy
- ✅ Analisis data dengan Pandas
- ✅ Membaca dan membersihkan dataset

## 🚀 Cara Mulai

1. Buka Jupyter Notebook
2. Mulai dari `01_python_fundamentals.ipynb`
3. Jalankan setiap cell dan pahami outputnya
4. Kerjakan latihan di setiap notebook

## 📝 Prerequisites

Tidak ada! Ini adalah starting point Anda.
