## 🧠 Learning Techniques

### 1. **Active Recall** 🔁

**Don't just re-read!** Test yourself frequently.

**How to apply:**
```
After each section:
1. Close notebook
2. Write down from memory:
   - What did I learn?
   - Key concepts?
   - Code syntax?
3. Compare with actual content
4. Note gaps untuk re-study
```

**Example questions:**
- "How do I create NumPy array?"
- "What's difference between list dan array?"
- "When to use broadcasting?"

---

### 2. **Spaced Repetition** 📆

**Review at increasing intervals:**

```
Day 1: Learn topic
Day 2: Review (1 day later)
Day 4: Review (2 days later)
Day 7: Review (3 days later)
Day 14: Review (7 days later)
Day 30: Review (2 weeks later)
```

**Tools:**
- Anki (flashcard app with spaced repetition)
- Physical flashcards
- Google Calendar reminders

---

### 3. **Feynman Technique** 🎓

**Learn by teaching/explaining:**

```
1. Choose topic (e.g., "NumPy broadcasting")

2. Explain aloud seperti mengajar anak kecil:
   "Broadcasting adalah cara NumPy untuk operasi 
    pada arrays dengan shapes berbeda..."

3. Identify gaps - stuck explaining? That's your weak point!

4. Review material untuk fill gaps

5. Simplify explanation further

6. (Optional) Write blog post atau create video
```

**Where to "teach":**
- Rubber duck debugging (literally explain to rubber duck)
- Blog/Medium post
- YouTube video
- Discord/Reddit post helping others
- Study group

---

### 4. **Pomodoro Technique** 🍅

**For focused study sessions:**

```
1. Set timer 25 minutes
2. Focus ONLY on one task
3. Take 5 minute break
4. Repeat 4x
5. Take longer 15-30 min break

Cycle:
[25min work] → [5min break] → 
[25min work] → [5min break] → 
[25min work] → [5min break] → 
[25min work] → [30min break]
```

**Tips:**
- Phone di mode silent
- Close unnecessary tabs
- Have water/snacks ready
- Track completed pomodoros (motivating!)

---

### 5. **Interleaving** 🔀

**Mix different topics rather than blocking:**

**Don't:**
```
Monday: 8 hours NumPy arrays only
Tuesday: 8 hours Pandas only
```

**Do:**
```
Monday Morning: NumPy arrays (2h)
Monday Afternoon: Pandas DataFrames (2h)
Monday Evening: NumPy indexing (2h)
```

**Why:** Brain builds stronger connections when switching contexts

### Code Snippets Collection

Keep a "cheat sheet" notebook:

```python
# NUMPY CHEAT SHEET

## Array Creation
np.array([1, 2, 3])              # From list
np.zeros((3, 4))                 # 3x4 zeros
np.ones((2, 2))                  # 2x2 ones
np.arange(0, 10, 2)              # [0, 2, 4, 6, 8]
np.linspace(0, 1, 5)             # 5 points from 0 to 1
np.random.rand(3, 3)             # 3x3 random [0,1)

## Indexing
arr[0]                           # First element
arr[-1]                          # Last element
arr[1:4]                         # Slice
arr[arr > 5]                     # Boolean indexing

## Operations
arr.mean()                       # Average
arr.std()                        # Standard deviation
arr.reshape(2, 5)                # Reshape
np.dot(a, b)                     # Matrix multiplication
```

**Update as you learn!**

## 🚨 Dealing with Challenges

### Feeling Overwhelmed? 😰

**Strategies:**
1. **Break it down** - Smaller chunks (one topic per day)
2. **Take break** - One day off dapat refresh mind
3. **Review basics** - Sometimes you need stronger foundation
4. **Ask for help** - Community is there!
5. **Accept plateau** - Learning isn't linear

---

### Stuck on Concept? 🤔

**Try 3-Resource Rule:**
```
1. Read tutorial (e.g., this repository)
2. Watch video (e.g., YouTube)
3. Do practice problem (e.g., Kaggle)
```

If still stuck, maybe skip for now and return later. Sometimes later concepts make earlier ones click!

---

### Losing Motivation? 😴

**Reflect:**
- Why did I start this?
- What's my end goal?
- How far have I come? (Look at week 1 progress!)

**Shake it up:**
- Change study location
- Study with friend
- Try different resources
- Build fun project (game, tool)
